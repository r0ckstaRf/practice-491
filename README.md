# CoffeeCare (WPF + MySql.Data + JWT)

Учебное приложение «Сеть кофеен самообслуживания» выполнили Каметов Лев и Бабодей София. Роли: администратор, диспетчер, менеджер, техник.

## Запуск (5 шагов)
1. Запустите MySQL (OpenServer / XAMPP / MySQL Server), порт 3306.
2. В phpMyAdmin создайте базу `coffeecare` (utf8mb4) и импортируйте `database/coffeecare.sql`.
3. Если у `root` есть пароль или другой порт - поправьте `ConnStr` в файле `Db.cs`.
4. Откройте `CoffeeCare.csproj` в Visual Studio (нужна нагрузка «Разработка классических приложений .NET»), дождитесь восстановления NuGet.
5. Нажмите F5. При первом входе программа сама создаст таблицу `login_log` и демо-данные.

## Права ролей
- Администратор: учетные записи, назначение ролей, точки и кофемашины, журнал входов.
- Диспетчер: заявки, назначение техников, просмотр состояния кофемашин.
- Менеджер: напитки и цены, учет продаж, выручка, отчет в CSV.
- Техник: свои заявки, смена статуса, протокол.

## Что где
- `Db.cs` - подключение и запросы через MySql.Data (параметризованные).
- `Auth.cs` - вход, bcrypt, JWT (HS256, 12 часов), журнал входов в `login_log`.
- `MainWindow.xaml.cs` - экраны и проверка JWT + роли перед каждым действием.
- `Seeder.cs` - демо-данные.

## Журнал входов
Пишутся: успешный вход, неверный пароль, неизвестный email, блокировка, выход, попытки без прав.
Видно во вкладке «Журнал входов» (только админ). 5 неудач за 10 минут - вход временно закрыт.
